# پروژه اندروید SMS CRM

این پروژه شامل کد کامل برنامه اندروید ارسال پیامک با متغیر `{name}`، ذخیره اطلاعات مخاطب و نام شرکت در دیتابیس SQLite، انتخاب سیم‌کارت (۱ یا ۲) و خروجی اکسل (CSV) است.

## روش ساخت خودکار فایل APK با GitHub Actions (بدون نیاز به نصب Android Studio)

1. وارد اکانت **GitHub** خود شوید و یک مخزن (Repository) جدید بسازید.
2. محتویات این فایل ZIP را از حالت فشرده خارج کرده و در مخزن گیت‌هاب خود آپلود (Push) کنید.
   - **نکته مهم هنگام آپلود از طریق مرورگر:** پوشه `.github/workflows/build.yml` به دلیل شروع شدن با نقطه (`.`) ممکن است در ویندوز مخفی باشد. مطمئن شوید فایل `.github/workflows/build.yml` نیز آپلود شده است.
3. در صفحه مخزن گیت‌هاب، وارد تب **Actions** شوید.
4. پس از اتمام تیک سبز مرحله **Build Android APK** (حدود ۲ تا ۳ دقیقه)، روی آن کلیک کنید و از بخش **Artifacts** در پایین صفحه، فایل **SMS-CRM-Debug-APK** را دانلود نمایید.
